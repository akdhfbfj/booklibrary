# 우리 반 그림책 도서관

학생들이 그림책을 쓰고, 친구 책을 읽고, 감상평을 남기는 학급용 웹 도서관이에요.
파일 하나(`index.html`)와 무료 Firebase로 돌아가서, 반마다 따로 복사해 쓸 수 있어요.

## 처음 설정하기 (반마다 한 번, 약 20분)

### 1. Firebase 준비
1. https://console.firebase.google.com 에서 **프로젝트 추가** (애널리틱스는 꺼도 돼요)
2. **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`)
3. Firestore **규칙** 탭에 아래를 붙여 넣고 **게시**
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{col}/{doc} {
         allow read, write: if col.matches('storybook_.*');
       }
     }
   }
   ```
4. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹(</>)** 앱 등록 → `firebaseConfig` 복사

### 2. 우리 반 파일 만들기
1. `index.html`을 브라우저로 열면 "연습 모드" 안내가 보여요. **처음 설정하기**를 눌러요.
2. 반 이름, 선생님 비밀번호, 마지막 번호, 없는 번호, firebaseConfig를 넣고 **연결 확인**을 눌러요.
3. "연결 성공"이 나오면 **파일 만들기**를 눌러요. 우리 반 전용 `index.html`이 받아져요.

### 3. GitHub Pages에 올리기
1. GitHub에서 **New repository** (Public)
2. **Add file → Upload files**로 우리 반 `index.html`(+ 예시 책을 쓰려면 `examples.json`)을 올리고 **Commit changes**
3. **Settings → Pages**에서 Branch를 `main`으로 고르고 **Save**
4. 1~2분 뒤 `아이디.github.io/저장소이름` 주소를 학생들에게 알려 주세요.

### 4. 예시 책 넣기 (선택)
선생님 모드 → **도서관 관리 → 예시 책 꾸러미 불러오기**를 누르면 같은 곳에 올린 `examples.json`의 예시 책이 들어가요.

## AI 예시 책 도우미 (무료)
선생님 모드 → 도서관 관리 → **AI 예시 책 도우미**. 돈이 드는 API 없이, 무료 Gemini 앱(gemini.google.com)에 복사·붙여넣기로 만들어요.
1. 줄거리, 학년, 쪽 수, 그림체, 주인공 모습을 적고 **글 질문 만들기** → **질문 복사** → Gemini에 붙여 넣기
2. Gemini 답을 통째로 복사해 붙여 넣고 **답 읽기** (쪽별 글과 그림 장면이 자동으로 나뉘어요)
3. 칸마다 **복사하고 새 채팅 열기** → Gemini 새 채팅에 붙여 넣기 → 나온 그림을 오른쪽 클릭 **이미지 복사** → 도우미에서 **Ctrl+V** (내려받은 파일은 '그림 고르기' 또는 '여러 장 한꺼번에 넣기')
4. **예시 책으로 저장**. 끝 쪽에 "Gemini와 함께 만든 예시 책"이 표시돼요.

- **그림마다 새 채팅에서** 그려요. 같은 대화창에서 이어 그리면 Gemini가 앞 그림을 고쳐서 비슷한 그림이 반복돼요. 주인공 모습은 질문 속 생김새 설명으로 맞춰지고, 구도(멀리서, 가까이, 옆에서, 위에서 등)는 쪽마다 자동으로 바뀌어요.
- 실제 연예인, 유명인을 닮게 해 달라는 표현은 쓰지 마세요. 거절되거나 초상권 문제가 생길 수 있어요.
- 무료 Gemini는 사용량 한도가 있어요. 다 차면 도우미를 닫았다가 몇 시간 뒤 다시 열면 이어서 할 수 있어요 (만들던 내용은 그 기기에 저장돼요).
- 학교 계정에서 Gemini가 막혀 있으면 개인 구글 계정으로 쓰세요.

## 선생님 모드 → 도서관 관리

| 기능 | 설명 |
|---|---|
| 백업 받기 / 불러오기 | 책, 그림, 감상평, 설정을 파일 하나로 보관하고 되살려요 |
| 새 학년 준비 | 백업을 자동으로 받은 뒤 학생 자료를 지워요. 예시 책과 책장, 설정은 남아요 |
| AI 예시 책 도우미 | 줄거리만 정하면 Gemini(무료)로 글과 삽화를 받아 예시 책을 만들어요 |
| 예시 책 꾸러미 불러오기 | 같은 곳에 있는 `examples.json`의 예시 책을 넣어요 |
| 책 파일 가져오기 / 내보내기 | 책 한 권(또는 우리 반 예시 책 전부)을 파일로 주고받아요 |
| 감상평 설정 | 바로 보이기 / 선생님이 확인한 뒤 보이기, 막을 낱말 추가 |
| 이웃 반 도서관 | 다른 반 도서관 주소를 넣으면 책장 아래에 '구경 가기' 단추가 생겨요 |
| 도서관 이름 | "○○ 그림책 도서관" 앞부분을 바꿔요 |
| 설정 파일 만들기 | 비밀번호·번호를 바꾼 새 파일, 또는 다른 반에 줄 빈 파일을 받아요 |

## 학생 화면에 추가된 것
- **직접 그리기**: 쪽과 표지에 바로 그림을 그려 넣어요 (색 10가지, 다른 색, 지우개, 굵기 3단계, 되돌리기)
- **읽어 주기**: 책을 소리 내어 읽고 다음 쪽으로 저절로 넘겨요
- **반응**: 끝까지 읽으면 😂 😍 😮 😢 👏 중 하나를 남겨요 (번호마다 책 한 권에 하나씩)
- **가정 공유**: 선생님이 책 화면에서 '가정 공유'를 누르면 그 책만 보이는 링크와 QR이 나와요

## 알아 둘 점
- 선생님 비밀번호는 파일 안에 들어 있어서, 페이지 소스를 열면 볼 수 있어요. 다른 곳에서 쓰는 비밀번호는 쓰지 마세요.
- 가정 공유 링크는 그 책만 보여 주지만, 도서관 주소를 아는 사람은 전체 책장도 볼 수 있어요.
- 무료 한도(저장 1GB, 하루 읽기 5만 회)는 한 반이 쓰기에 넉넉해요.
